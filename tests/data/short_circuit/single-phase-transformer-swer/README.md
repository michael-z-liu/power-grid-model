# Validation case: short circuit in a SWER chain with single-phase transformers

IEC 60909 short circuits (maximum voltage scaling) in the `swer-chain` network of `power_flow/single-phase-transformer`, without loads: a 22 kV three-phase feeder, a SWER isolating transformer (`ab` → `a`, 22 kV / 12.7 kV, earth electrode of 5 + j0.1 Ω), a 20 km SWER line and two SWER distribution transformers (`a` → `a`, 12.7 kV / 240 V, one with a from-side tap at +2.5 %). It is a batch of four scenarios:

- single-phase to ground on phase a at the end of the SWER line, bolted (`r_f` = 0);
- the same with `r_f` = 10 Ω;
- single-phase to ground on phase a at the 240 V node behind the tapped transformer, bolted;
- three-phase with `r_f` = 0.5 Ω at the three-phase node of the isolating transformer, which is solved asymmetrically because the network has single-phase nodes.

The current of the earth electrode is the to-side winding current of the isolating transformer. In a SWER fault it carries the fault current plus the charging current of the SWER line.

## Generation

The input (`input.json`), the OpenDSS model (`test.dss`) and the expected output are generated by `tests/data/generators/reduced_phase_opendss_cases.py`, with OpenDSS (via `opendssdirect.py`) as the reference solver. Do not edit the files by hand; change the case definition in the script and regenerate. The modelling choices and the command to run are described at the top of the script.
