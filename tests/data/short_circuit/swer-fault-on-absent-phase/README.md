# Validation case: short circuit on a phase that is absent at the SWER node

A single-phase-to-ground fault on phase **b** at the end of the SWER line (node 4) in the `swer-chain` network of `power_flow/single-phase-transformer`, without loads: a 22 kV three-phase feeder (nodes 1 and 2), a SWER isolating transformer (`ab` → `a`, 22 kV / 12.7 kV, earth electrode of 5 + j0.1 Ω), a 20 km SWER line (nodes 3 and 4) and two SWER distribution transformers (`a` → `a`, 12.7 kV / 240 V) to the 240 V nodes 5 (behind the transformer with a from-side tap at +2.5 %) and 6. Node 4 only has phase a, so the fault cannot be applied there. The short-circuit calculation raises `InvalidShortCircuitPhaseOrType` with the fault ID and both phase sets:

> The short circuit phases (b) of fault 601 are not all present at its node 4 (node phases: a); this short circuit type cannot be applied there

Without this check the fault would silently give a zero fault current. The phases of a fault must be present at its node; a SWER node takes single-phase-to-ground faults on phase a, which is also the default phase of that fault type. The expected output only lists the component IDs; there is no OpenDSS reference.
