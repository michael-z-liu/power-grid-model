# Validation case: state estimation with a delta load

A small three-phase network with a delta-connected `asym_load`, for which state estimation must raise `ReducedPhaseNotSupported` ("State estimation is not supported in a network with delta-connected loads or generators."). The input is generated with the same definition as the other delta-load cases; there is no OpenDSS reference.

## Generation

The input (`input.json`), the OpenDSS model (`test.dss`) and the expected output are generated by `tests/data/generators/reduced_phase_opendss_cases.py`, with OpenDSS (via `opendssdirect.py`) as the reference solver. Do not edit the files by hand; change the case definition in the script and regenerate. The modelling choices and the command to run are described at the top of the script.
