# Validation case: single-phase transformers in a SWER chain

Asymmetric power flow from a 22 kV three-phase feeder through a SWER isolating transformer (`ab` → `a`, 22 kV / 12.7 kV, earth electrode of 5 + j0.1 Ω) into a 20 km single-wire earth return line, with two SWER distribution transformers (`a` → `a`, 12.7 kV / 240 V), one of them with a from-side tap at +2.5 %. It has const_pq loads on the SWER nodes and const_pq plus const_y loads on the 240 V nodes. All transformers have i0 = p0 = 0.

## Generation

The input (`input.json`), the OpenDSS model (`test.dss`) and the expected output are generated by `tests/data/generators/reduced_phase_opendss_cases.py`, with OpenDSS (via `opendssdirect.py`) as the reference solver. Do not edit the files by hand; change the case definition in the script and regenerate. The modelling choices and the command to run are described at the top of the script.
