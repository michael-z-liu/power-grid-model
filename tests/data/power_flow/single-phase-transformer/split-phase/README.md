# Validation case: centre-tapped (split-phase) single-phase transformers

Asymmetric power flow from a 22 kV three-phase feeder into two 240-0-240 V split-phase secondaries (`to_connection` = `ab_center_tapped`, `u2` = 480 V, split-phase nodes with `u_rated` = 240·√3 V):

- through a SWER isolating transformer (`ab` → `a`, 22 kV / 12.7 kV, earth electrode of 5 + j0.1 Ω) and a 20 km SWER line to an `a` → centre-tapped transformer (12.7 kV / 480 V, 25 kVA, the default Kersting split of `uk`/`pk`, solidly earthed centre tap, from-side tap at +2.5 %), with a 0.3 km `ab` service line (with neutral) off the split-phase node;
- through a `bc` → centre-tapped transformer (22 kV / 480 V, 50 kVA, clock 6, `uk_half` = 0.022 and `pk_half` = 200 W, centre tap earthed through an electrode of 0.5 + j0.05 Ω).

The loads are unbalanced wye loads on the legs a and b (const_pq, const_i and const_y), so Newton-Raphson (linear start) and iterative current (average-source start, which uses the split-phase slot pattern) both iterate. All transformers have i0 = p0 = 0.

## Generation

The input (`input.json`), the OpenDSS model (`test.dss`) and the expected output are generated by `tests/data/generators/reduced_phase_opendss_cases.py`, with OpenDSS (via `opendssdirect.py`) as the reference solver. Do not edit the files by hand; change the case definition in the script and regenerate. The modelling choices and the command to run are described at the top of the script.
