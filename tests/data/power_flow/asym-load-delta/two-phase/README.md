# Validation case: phase-to-phase loads on two-phase laterals

Asymmetric power flow on an 11 kV feeder with two-phase laterals: an `ab` line with a neutral to node 3, an `ab` line without a neutral on to node 4, and an `ac` line to node 5. The delta loads have one non-zero entry at the two-phase nodes:

- node 3: load 301, const_pq, 80 kW + j25 kvar on ab;
- node 4: load 302, const_i, 50 kW + j15 kvar on ab, and the wye load 303, const_y, on a and b;
- node 5 (phases a and c): load 304, const_pq, 60 kW + j20 kvar on ca;
- node 2 (three-phase): load 305, const_y, on ab, bc and ca.

In OpenDSS every non-zero delta entry is a 1-phase `Load` with `conn=delta` between its two phases (`kV` = the rated branch voltage, `model` 1, 5 or 2). Before the reference is written, the generator checks that the power of every OpenDSS delta load equals $\sum_k S_k (|U_p - U_q| / U_{\Delta,nom})^n$ to 1e-9 relative, so the branch-voltage base and the voltage dependence are the same as in PGM. The reference also has the `asym_load` and `asym_gen` outputs (`p`, `q` and `i` per phase, the OpenDSS terminal values), which for a delta load are the phase quantities that PGM reports. The branch base is $u_{rated}$ at every node ($U_{\Delta,nom} = \sqrt3$, the three-phase slot pattern). Newton-Raphson and iterative current are checked.

## Generation

The input (`input.json`), the OpenDSS model (`test.dss`) and the expected output are generated by `tests/data/generators/reduced_phase_opendss_cases.py`, with OpenDSS (via `opendssdirect.py`) as the reference solver. Do not edit the files by hand; change the case definition in the script and regenerate. The modelling choices and the command to run are described at the top of the script.
