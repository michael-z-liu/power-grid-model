# Validation case: 480 V loads on split-phase secondaries, flat start

The network and loads of `split-phase`, solved with Newton-Raphson from the flat start (`calculation_initialization` = `flat`), which applies the split-phase slot pattern to the start values. Iterative current is checked as well; it ignores `calculation_initialization` and always starts from the average-source start, which here equals the flat start (one source with `u_ref` 1.0).

In OpenDSS every non-zero delta entry is a 1-phase `Load` with `conn=delta` between its two phases (`kV` = the rated branch voltage, `model` 1, 5 or 2). Before the reference is written, the generator checks that the power of every OpenDSS delta load equals $\sum_k S_k (|U_p - U_q| / U_{\Delta,nom})^n$ to 1e-9 relative, so the branch-voltage base and the voltage dependence are the same as in PGM. The reference also has the `asym_load` and `asym_gen` outputs (`p`, `q` and `i` per phase, the OpenDSS terminal values), which for a delta load are the phase quantities that PGM reports.

## Generation

The input (`input.json`), the OpenDSS model (`test.dss`) and the expected output are generated by `tests/data/generators/reduced_phase_opendss_cases.py`, with OpenDSS (via `opendssdirect.py`) as the reference solver. Do not edit the files by hand; change the case definition in the script and regenerate. The modelling choices and the command to run are described at the top of the script.
