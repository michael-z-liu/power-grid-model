# Validation case: 480 V loads on split-phase secondaries

The split-phase network of `power_flow/single-phase-transformer/split-phase` (two 240-0-240 V centre-tapped secondaries fed from 22 kV, one through a SWER line, with an `ab` service line) with its unbalanced 240 V wye loads, plus 480 V leg-to-leg loads (delta, ab entry only):

- node 5 (split-phase node of transformer 152): load 307, const_pq, 4 kW + j1 kvar;
- node 7 (end of the service line, which carries the split-phase pattern): load 308, const_i, 2 kW + j0.5 kvar;
- node 6 (split-phase node of transformer 153, clock 6, centre-tap electrode): load 309, const_y, 5 kW + j1 kvar.

At a split-phase node the branch base is 480 V ($U_{\Delta,nom} = 2$ on the phase-to-earth base of 240 V). In OpenDSS every non-zero delta entry is a 1-phase `Load` with `conn=delta` between its two phases (`kV` = the rated branch voltage, `model` 1, 5 or 2). Before the reference is written, the generator checks that the power of every OpenDSS delta load equals $\sum_k S_k (|U_p - U_q| / U_{\Delta,nom})^n$ to 1e-9 relative, so the branch-voltage base and the voltage dependence are the same as in PGM. The reference also has the `asym_load` and `asym_gen` outputs (`p`, `q` and `i` per phase, the OpenDSS terminal values), which for a delta load are the phase quantities that PGM reports. Newton-Raphson and iterative current are checked.

## Generation

The input (`input.json`), the OpenDSS model (`test.dss`) and the expected output are generated by `tests/data/generators/reduced_phase_opendss_cases.py`, with OpenDSS (via `opendssdirect.py`) as the reference solver. Do not edit the files by hand; change the case definition in the script and regenerate. The modelling choices and the command to run are described at the top of the script.
