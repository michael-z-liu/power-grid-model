# Validation case: delta loads on a three-phase network

Asymmetric power flow on an 11 kV three-phase network (no reduced-phase nodes) with delta-connected (`connection` = `delta`) loads of every type:

- node 2: load 301, const_pq, 150 kW + j50 kvar on each of ab, bc and ca (a native 3-phase delta load in OpenDSS), and generator 401, const_pq, 50 kW + j10 kvar on bc;
- node 3 (behind a line with a neutral and c0/c1 capacitance): load 302, const_i, on ab and ca; load 303, const_y, on bc and ca; and the wye load 304, const_pq, on a and b.

In OpenDSS every non-zero delta entry is a 1-phase `Load` with `conn=delta` between its two phases (`kV` = the rated branch voltage, `model` 1, 5 or 2), and load 301 is one native 3-phase `conn=delta` load. Before the reference is written, the generator checks that the power of every OpenDSS delta load equals $\sum_k S_k (|U_p - U_q| / U_{\Delta,nom})^n$ to 1e-9 relative, so the branch-voltage base and the voltage dependence are the same as in PGM. The reference also has the `asym_load` and `asym_gen` outputs (`p`, `q` and `i` per phase, the OpenDSS terminal values), which for a delta load are the phase quantities that PGM reports. Newton-Raphson and iterative current are checked.

## Generation

The input (`input.json`), the OpenDSS model (`test.dss`) and the expected output are generated by `tests/data/generators/reduced_phase_opendss_cases.py`, with OpenDSS (via `opendssdirect.py`) as the reference solver. Do not edit the files by hand; change the case definition in the script and regenerate. The modelling choices and the command to run are described at the top of the script.
