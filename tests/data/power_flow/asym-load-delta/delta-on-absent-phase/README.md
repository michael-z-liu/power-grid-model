# Validation case: delta entry on an absent phase

A delta-connected `asym_load` with a non-zero bc entry at a node behind an `ab` line, which has no phase c. The power flow must raise `LoadGenOnAbsentPhase`: a delta entry needs both of its phases at the node. There is no OpenDSS reference.

## Generation

The input (`input.json`), the OpenDSS model (`test.dss`) and the expected output are generated by `tests/data/generators/reduced_phase_opendss_cases.py`, with OpenDSS (via `opendssdirect.py`) as the reference solver. Do not edit the files by hand; change the case definition in the script and regenerate. The modelling choices and the command to run are described at the top of the script.
