# Validation case: asym_line with two phases (b, c) and a neutral, reduced by OpenDSS

Asymmetric power flow in a two-node network with one two-phase `asym_line` (phases b, c, with neutral) and an unbalanced two-phase load. The newton_raphson and iterative_current methods are validated.

The point of this case is an independent check of the neutral Kron reduction. In the other generated cases with a neutral (`two-phase-ab`, the feeder cases) the generator gives OpenDSS a matrix that numpy has already Kron-reduced. Here `test.dss` defines a `LineCode` with `nphases=3`, the full 3x3 R and X matrices including the neutral, and `Kron=yes Neutral=3`, so OpenDSS reduces the neutral itself; the line then connects only the two phase terminals (`.2.3`). The PGM input holds the unreduced `r_bb`, `r_cb`, `r_nb`, `r_nn` etc. entries, which PGM reduces with its own closed-form Kron. The b/c slot handling (phase a absent) is exercised as well.

## Generation

The input (`input.json`), the OpenDSS model (`test.dss`) and the expected output are generated by `tests/data/generators/reduced_phase_opendss_cases.py`, with OpenDSS (via `opendssdirect.py`) as the reference solver. Do not edit the files by hand; change the case definition in the script and regenerate. The modelling choices and the command to run are described at the top of the script. While generating, the script asserts that OpenDSS reduced the LineCode to two phases and that its reduced matrix equals the numpy one.
